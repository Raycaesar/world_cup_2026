This project is a lightweight static site using index.html, style.css, and data.json.

Rules:
- Do not change data.json scoring rules unless explicitly asked.
- Do not push to GitHub unless explicitly asked.
- Keep the site lightweight: no build step, no Node dependency, no React/Vue.
- Prefer vanilla HTML/CSS/JS.
- Keep the dark World Cup theme.
- Do not make animations distracting.
- Respect reduced-motion users with @media (prefers-reduced-motion: reduce).
- Preserve existing data structure unless explicitly asked.
- Improve mobile layout carefully.
- After edits, check the page in desktop and mobile widths.
- Do not add infinite background animation unless explicitly requested.
- Do not add spinning ornaments, rotating disks, moving pitch lines, or animated light sweeps.
- Prefer designer restraint over decorative effects.
- Section color variation is encouraged, but keep the page coherent.
- The VS element must never overlap Ray or GPT score cards.
- Any football icon must look like a football and remain decorative.
